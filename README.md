📚 Temario y Mini Conceptos
MATEO MANCHENO
1. HTML (HyperText Markup Language)

Es el lenguaje de marcado estándar para la creación de páginas web. Define la estructura y el contenido del sitio mediante etiquetas (elementos como textos, imágenes, formularios y enlaces).

2. CSS (Cascading Style Sheets)

Es el lenguaje de diseño gráfico utilizado para definir y crear la presentación de un documento estructurado en HTML. Controla el diseño, colores, fuentes, adaptabilidad (responsive design) y animaciones.

3. JavaScript

Lenguaje de programación interpretado y de alto nivel. Permite añadir dinamismo, interactividad y lógica a las páginas web (manipulación del DOM, eventos, peticiones asíncronas).

4. TypeScript

Un superconjunto de JavaScript desarrollado por Microsoft que añade tipado estático opcional. Ayuda a detectar errores en tiempo de desarrollo, mejora la escalabilidad y facilita el mantenimiento de código complejo.

5. React.js

Una librería de JavaScript desarrollada por Meta enfocada en la creación de interfaces de usuario basadas en componentes reutilizables. Utiliza un DOM virtual para optimizar el rendimiento y maneja el estado de la aplicación de forma eficiente.

6. NestJS

Un framework de Node.js progresivo para construir aplicaciones de servidor eficientes y altamente escalables. Utiliza TypeScript por defecto, integra una arquitectura modular robusta e implementa conceptos orientados a objetos y de inyección de dependencias.
